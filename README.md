# Portfólio Pessoal – HTML e CSS

Este repositório contém um projeto de portfólio pessoal desenvolvido com HTML e CSS como atividade prática durante uma aula do curso do **Instituto PROA**. O projeto tem como objetivo praticar os fundamentos do desenvolvimento web, a organização de conteúdo e a estilização de páginas, sendo realizado para fins acadêmicos e de aprendizado.

O portfólio ainda não está completo, pois foi desenvolvido como exercício para aplicar os conhecimentos adquiridos durante o curso.

## Funcionalidades

- **Estrutura HTML:** Organização do conteúdo da página utilizando elementos HTML.
- **Estilização com CSS:** Aplicação de cores, fontes, espaçamentos e outros elementos visuais.
- **Apresentação Pessoal:** Criação de uma estrutura inicial para apresentar informações pessoais e profissionais.
- **Organização do Conteúdo:** Distribuição dos elementos para facilitar a leitura e a navegação.
- **Desenvolvimento Web:** Aplicação prática dos conceitos básicos de HTML e CSS.

## Objetivo do Projeto

O projeto foi desenvolvido com finalidade acadêmica e de treinamento, visando consolidar conhecimentos fundamentais em HTML e CSS. Também busca desenvolver habilidades de estruturação, organização e estilização de páginas web, servindo como ponto de partida para a criação de um portfólio pessoal mais completo.

## Tecnologias Utilizadas

- **HTML5:** Estruturação e organização do conteúdo.
- **CSS3:** Estilização e apresentação visual da página.

## Como Executar

1. Clone ou baixe este repositório.
2. Abra a pasta do projeto.
3. Localize o arquivo `index.html`.
4. Abra o arquivo em um navegador para visualizar o portfólio.

## Aprendizados

Durante o desenvolvimento, foram praticados conceitos básicos de estrutura HTML, organização de conteúdo, seletores CSS, aplicação de estilos e construção de páginas web.

## Referência e Créditos

Projeto desenvolvido para fins educacionais, com base no tutorial [Create A Portfolio Website Using HTML and CSS Only](https://www.youtube.com/watch?v=-u3vE84Wo_U), disponível no YouTube. O código foi acompanhado e reproduzido com o objetivo de praticar os conceitos de HTML e CSS apresentados.
